# Archive Center 4.3.0-test.11 — 사용자 중심 서사 가이드 강도

날짜: 2026-09-07. 상태: `implemented_unverified`.
test.10의 보완을 포함하며, 이번 변경은 출판사 가이드의 단계 차이를 다룬다.

## 사용자 확정 방향

사용자는 강하게 이상에서 가이드의 일부 실행을 요구하는 것을 허용했다.
이야기의 방향, 설정 변경, 진행 속도, 사용자 선택과 창작 표현의 자유를 우선한다.
따라서 모든 단계를 선택적 참고로 전달하던 test.10의 방식을 세분화한다.

| 강도 | 출판사 및 본문에 전달하는 적용 수준 |
| --- | --- |
| 없음 | 출판사 호출과 가이드 없음. 기존 기억 주입 유지 |
| 약하게 | 연속성·행동·뉘앙스에 관한 짧은 선택적 참고 |
| 중간 | 사용자 방향과 인물 반응·장면 맥락을 연결한 권고 |
| 강하게 | 사용자가 선택한 방향·행동을 구체적 묘사와 반응으로 실행 |
| 매우 강하게 | 행동·반응·결과가 이어지는 이번 응답의 전개 |
| 최대로 | 현재 응답의 도입·전개·도달점을 구체화한 실행 안내 |

강한 단계에서도 사용자가 고르는 이야기와 진행 속도가 기준이다. 조용한 대화,
기다림, 실패한 시도, 아직 결정하지 않은 선택도 그 맥락에 맞게 구체화할 수 있다.
성공·새 사건·관계 변화·긴장 상승 자체를 강도와 동일시하지 않는다.

## 동작과 소유권

Go의 기존 `publisherStrengthProfile()`에서 단계별 적용 설명을 만들고,
실제 출판사 입력과 본문이 받는 가이드 양쪽에 전달한다. 간결형·표준형·명시형
모두 같은 강도 기준을 표현한다. 강하게 이상을 일괄적으로 생략 가능한 아이디어로
설명하던 문구를 정리한다.

기본 출력은 맥락·사용자 지향·다음 전개·톤 네 필드다. 과거 응답 형식 호환,
항목 내용·순서·수락, 기억·로어북 선정, 단일 출판사 호출, 온도·추론·토큰 한도,
서사 안내 예산과 기존 저장·리롤 동작은 유지한다. 추가 AI나 후처리 호출은 없다.
가이드 강도와 장면의 압박 수준은 별개다. 저장된 사용자 프롬프트는 덮어쓰지 않는다.

UI의 한국어·영어·일본어 설명을 실제 적용 수준에 맞췄다. JavaScript는 설명과
빌드 식별자만 변경하며 강도 정책은 Go가 소유한다.

## 검증

- 신규 회귀는 실제 `/prepare-turn` → 제공자 HTTP 경계 → 최종 `auxiliary_text`를
  없음 포함 6개 강도 × 3개 표시 형식으로 검사했다. 각 강도의 정책이 출판사와
  본문 양쪽에 전달되고, 같은 추천의 원문·순서·quiet 톤·기억 주입이 유지된다.
- 기본 3,000자 안내 예산 안에서 최대로를 포함한 모든 활성 강도의 가이드가
  전달됐다. 모델·온도·추론·출력 토큰·호출 횟수와 예산은 강도로 바꾸지 않는다.
- 신규 strong 회귀에 수정 전 `group_proxy.go`를 Go overlay로 대입하면
  `strength policy did not reach actual provider input: map[]`로 실패했다.
  현재 파일을 교체하지 않고 기존 문제를 검출하는지 확인했다.
- Publisher 관련 검사 통과(0.591초), HTTP 영역 전체 회귀 통과(21.490초),
  JavaScript 실행형 회귀 통과(11.412초), `go vet ./internal/httpapi`,
  JavaScript 문법 및 `git diff --check` 통과.
- JavaScript는 이번 시작점 대비 추가 7줄/삭제 7줄이다. 세 언어의 도움말과
  네 빌드 식별자만 수정했다. 강도별 Go 정책을 JavaScript에서 복제하지 않는다.

안내 문장이 추가되므로 같은 서사 안내 예산에서 사용할 수 있는 나머지 공간은
조금 줄어든다. 기존 예산 처리와 저장한 프롬프트 수정본은 그대로 유지한다.
실제 RisuAI/모델에서 강도별 출력 차이가 나타나는지는 별도 확인 대상이다.
사용자 백엔드와 플러그인은 실행하거나 교체하지 않는다.

검사 기록: 작업 루트 `.tmp-feedback-43/test11-httpapi-tests.log`,
`test11-js-tests.log`, `test11-vet.log`. 변경 전 기준은 `test11-baseline`이다.
