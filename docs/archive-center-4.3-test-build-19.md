# Archive Center 4.3.0-test.19 — 기억 편집자 프롬프트 보완

날짜: 2026-09-08. 상태: `implemented_unverified`.

## 변경 내용

공통 지침과 다섯 전용 프롬프트를 현재 장면의 기억을 준비하는 편집자 역할로 정리했다.
근거의 현재 관련성·변화·관점을 설명하며 출판사 OFF에서도 본문 모델을 돕는다.

| 담당 | 보완한 관점 |
| --- | --- |
| 사건·진행 이력 | 앞선 원인과 관측된 변화, 현재 출발점의 연결 |
| 인물의 객관적 상태 | 소유·수량·능력·일시 상태와 그 변화의 실질적 관련성 |
| 개인 경험·관계·비밀 | 누가 어떻게 알게 되었고 관계와 이해가 어떻게 변했는지 |
| 세계·장소·물건 | 현재 상호작용에 필요한 환경·기능·기록된 조건 |
| 미해결 목표·복선 | 약속의 진행·완료·남은 부분과 현재 장면의 연결 |

사용자가 사건·속도·결말·설정 변경을 결정한다. 초안 작성·재작성·후처리를 추가하지 않았다.
기존 공개 근거 전달에 누락된 `request_reason`을 보완해 발신 담당과 확인 목적을 원문과
분리한다. 기존 두 차례 분석, 검색 한도, 비밀 범위, 선택 원문·순서 및 추천 없음 시
Go 선정을 유지한다. 요청 이유는 AI 해석이며 사실 저장이나 추가 왕복 호출이 아니다.

- [플러그인](../_test-builds/4.3.0-test.19/Archive%20Center%204.3.0-test.19%20Windows%20Auto%20Install%20Package/Archive%20Center.js)
- [시작 파일](../_test-builds/4.3.0-test.19/Archive%20Center%204.3.0-test.19%20Windows%20Auto%20Install%20Package/01_start_archive_center_windows.bat)

Go 백엔드도 새로 빌드했다. 플러그인과 백엔드를 함께 적용하고 실행은 사용자가 직접 한다.
JS 변경은 식별자 **4줄 추가 / 4줄 삭제**, 기능 로직 증가는 0줄이다.
공개 GitHub 릴리스는 4.2.0이며 이번 Windows 테스트 패키지를 게시하지 않았다.

Edge의 현재 여섯 프롬프트가 기존 기본값과 일치함을 확인한 뒤 빈 값으로 저장했다.
이는 기존 '백엔드 기본값 사용' 동작이며, 새 백엔드 시작 후 보완한 기본 프롬프트를 쓴다.
저장 성공과 전처리 OFF를 확인했다. 모델·키·온도·토큰 등 다른 입력은 편집하지 않았다.
다른 사용자의 직접 수정한 프롬프트를 자동 덮어쓰는 기능은 없다. 직접 수정한 값은
계속 우선하며, 새 기본값을 원하면 새 백엔드 연결 후 해당 항목의 기본값 복원을 사용한다.

## 검증

전달 이유가 빠지는 기존 동작에서 회귀가 실패했고, 수정 후 실제 등록된 `/prepare-turn`
생산 경로에서 수신 담당의 HTTP 입력에 이유가 원문·출처와 분리되어 도달했다.
출판사 OFF·성공·실패, 공개 근거 범위, 최종 주입 원문과 기존 검색·분석 횟수를 확인했다.
집중 시험 일반 21개+하위 33개, 전체 Go **35개 패키지·일반 3,847개+하위 783개** 통과.
전체에는 Host 생산 경로 422개가 포함된다. 소스·패키지 JS 구문 검사도 통과했다.
MariaDB 8개, Chroma 2개, 실제 제공자 1개, POSIX 실행 비트 1개는 환경상 생략했으며
별도의 두 도구 패키지는 시험 파일이 없다.

Go 1.26.6으로 활성 dirty 소스를 빌드했다. 관리 파일 53개 크기·해시·ZIP 일치,
플러그인·두 공용 프롬프트·SQL 13개 원본 일치, 시작 안내의 test.19 버전을 확인했다.
편집자 프롬프트는 별도 텍스트 파일이 아닌 Go 기본값에 포함된다.
ZIP **18,080,801바이트**. 기존 test.18 ZIP과 사용자 데이터는 보존했다.
