저장소 밖 통합 로드맵의 수정 전 사본은 로컬 진단 폴더의 `roadmap-before.md`에 보관했다.

플러그인과 새 Go 백엔드를 함께 적용한다. 백엔드는 사용자가 기존 실행을 종료한 뒤

사용자의 백엔드·DB를 시작하거나 중지하지 않았다.

**기본 프롬프트 적용:** 저장된 공통/담당 프롬프트가 빈칸이면 새 기본값이 적용된다.
저장된 문장이 있으면 그 사용자 설정을 유지한다. 새 기본값으로 시험하려면 전처리 설정의
공통 프롬프트와 다섯 담당 프롬프트에서 각각 **기본값 복원**을 누른 뒤 **전처리 설정 저장**을
누른다. 복원 전 사용자 편집본을 따로 보관하면 이전 프롬프트와도 비교할 수 있다.
API 키·모델·연결 설정은 이번 작업에서 변경하지 않았다.

## 한정된 세 가지 보완

1. **수신 결과 보존**: `search_requests`의 문자열 배열 외에 실제 관측된
   `{"question":"..."}` / `{"query":"..."}` 배열 항목도 질문 문자열로 읽는다.
   형식 보정으로 표시하며 선택 ID·설명·순서를 유지한다. 다른 잘못된 항목은 기존처럼
   개별 오류로 남기면서 뒤의 정상 항목을 읽는다. 기억 ID 해석 규칙은 바꾸지 않았다.
   분류별 정렬은 해당 담당의 목록을 사용하고, 사건 요약은 별도 요약 순서를 따른다.
   다른 담당의 같은 ID 언급이 소유 담당의 순서를 덮던 문제를 고쳤다.
2. **편집자 기본 프롬프트**: 공통 지침과 다섯 담당 지침에서 기록된 내용과 가능한
   관련 해석, 자료가 비워 둔 부분을 구별한다. 출처 시점·예정 시점·현재 장면,
   이론/실행 경험, 관계의 보유자, 지역 한정 설명, 상대적 마감 시점을 구체화했다.
   오래된 작은 기억도 물건·장소·경험 같은 단서를 통해 고를 수 있다. 사용자가 선택한
   전개와 창작 결정권은 우선하며 서사의 결과를 강제하는 지시는 추가하지 않았다.
3. **반복 출처 표기 축소**: 최종 노트의 출처 목록은 범례가 있는 짧은 키를 사용하고
   연속된 미확정 사항은 공통 공개 범위를 한 번 표시한다. 원문, 담당 설명·미확정 문장,
   출처 ID/턴·보유자·열람 범위와 null/미지정 구분을 유지한다. 진단의 전체 출처 목록과
   개별 항목은 그대로이며 출판사에도 전체 출처 구조가 전달된다.

test.21의 기본 기억 폭, 중요도와 시간의 분리, 기존 문자 예산은 유지한다.
추천 없음의 Go 선정과 보완 호출 실패 시 이전 추천 보존도 그대로다. 형식이 정상화된
보완 응답은 기존 정상 응답 경로로 적용된다. 검색·분석 횟수, 후처리 호출이나 추천을
잘라내는 조건은 추가하지 않았다.

## 검증 결과

- 신규 생산 함수 회귀는 기준 커밋에서 질문 객체·담당 순서·출처 표기 검사가 실패한 뒤
  수정본에서 통과했다. 정상화된 2차 추천이 실제 최종 기억/노트를 대체하고 3차 호출을
  만들지 않는 검사도 포함한다. 실제 호출 실패의 이전 결과 보존은 기존 회귀로 확인했다.
- 전체 Go **35개 패키지, 일반 시험 3,858개와 하위 시험 790개 통과**, 실패 0개.
  test.21을 기대하던 버전 표기 시험도 test.22로 맞추고 전체를 다시 통과했다. 실제 MariaDB 8개·Chroma
  2개·제공자 1개·POSIX 실행 비트 1개는 환경상 생략하며, 도구 두 패키지는 시험 파일이 없다.
- 공통/개별 기본값·사용자 설정이 실제 요청 조립에 전달되는 기존 시험도 실행했다.
  플러그인 구문과 버전 식별자 검사, 기존 OFF·추천 없음·일부 실패 회귀를 함께 검사했다.
- 사용자가 보낸 두 테스트의 **저장 응답 20개**를 실제 호출/해석 함수에 재입력했다.
  외부 제공자 경계만 로컬 시험 서버로 바꿨으며 **외부 AI 호출은 0회**다.
  기존 형식 오류 3건이 보정되고 ID/요약/설명 내용이 유지됐다. 고정된 최종 추천을 실제
  선정·노트·payload 함수에 통과시켜 정상 출판사/비활성/실패 상태의 전달도 확인했다.

| 고정 최종 추천 | 사실 / 요약 | 기억 문자 수 전후 | 노트 전 → 후 |
| --- | ---: | ---: | ---: |
| 전처리 + 출판사 자료 | 39 / 3 | 5,867 → 5,867 | 13,748 → 11,513 |
| 전처리 단독 자료 | 43 / 3 | 6,614 → 6,614 | 15,313 → 12,501 |

이 표는 선택 경계에 주어진 후보와 기존 최종 추천을 고정한 비교다. 직접 근거·로어북 등
나머지 입력은 재구성하지 않았으므로 사용자가 보낸 전체 입력 문자 수와는 다르다.
출처 목록과 개별 진단 항목은 전후 완전히 같고, 사실/요약 선정 집합과 원문도 같다.
확인된 목표 담당 순서만 수정됐다. 새 프롬프트로 AI가 새로 선택할 결과나 새 검색 결과를
예측한 표가 아니다. 약 16~18%의 노트 축소는 토큰/비용/품질 개선률을 뜻하지 않는다.

## 생성물과 남은 확인

기존 Windows 패키지 제작 경로로 활성 소스를 컴파일했다. 관리 파일 **53개**의 크기·해시와

README를 함께 갱신했다. 공개 릴리스는 4.2.0을 유지한다.
