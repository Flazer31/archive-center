# Archive Center 4.3.0-test.4

2026-09-06 전처리 설정 UI 수정 테스트 빌드. 공개 릴리스가 아니다.
사용자가 직접 설치·실행하도록 새 패키지만 생성한다.

## 수정 내용

제보 화면의 입력칸과 프롬프트에는 정의되지 않은 스타일 클래스가 사용되고 있었다.
담당별 접이식 카드, 모델 연결 영역, 넓은 프롬프트 편집 영역으로 다시 배치했다.
기존 설정 화면의 색상과 입력 양식을 적용하고 모바일에서는 한 열로 표시한다.
기존 가로 폼의 flex 배치가 세로 입력칸을 침범하는 문제도 실제 렌더링에서 확인해 수정했다.

- 다섯 담당은 각자 프롬프트를 편집·복원·저장한다.
- 출판사 연결 공유는 모델·API 연결 공유다. 각 호출에는 공통 규칙과 해당 담당의 전용
  프롬프트가 적용된다. Go의 기존 프롬프트 조합과 역할 기본 지침은 이번에 변경하지 않았다.
- 연결 공유 중에는 출판사 모델 안내를 표시한다. 해제하면 개별 연결 입력칸을 표시한다.
  입력칸을 숨겨도 따로 입력해 둔 모델·주소·키 값은 보존한다.
- 토큰·대기 시간·추론 설정은 담당별 세부 설정에, 후보 입력 한도와 공통 지침은 공통 설정에 둔다.
- 저장 영역은 다른 입력칸을 가리지 않도록 문서 흐름 안에 배치한다.
- **Go 백엔드 코드 변경 없음.** 패키지 버전 표시와 실행 파일의 변경 여부는 구분한다.
- JavaScript 변경량: test.3 패키지 대비 **94줄 추가, 23줄 삭제**.
  DOM·CSS·화면 이벤트·버전 표시 변경이며 기억 정책은 Go에 유지한다.

## 검증

- `node --check "Archive Center.js"`, JavaScript 회귀 패키지 전체, `git diff --check` 통과.
- `ops/preprocessing-ui-smoke.cjs`는 실제 패널 생성 함수와 전처리 설정 함수를 로컬
  브라우저 DOM에서 실행한다. 설정 API만 고정 시험 자료로 대체하며 네트워크를 차단한다.
- 1600 / 900 / 390px 화면에서 가로 넘침, 입력칸의 인접 열 침범, 흰색 기본 입력칸 여부를 검사했다.
- 모든 담당과 세부 설정을 펼친 개별 연결 모드도 검사했다.
- 한 담당의 프롬프트 수정·복원, 다른 담당 프롬프트 유지, 숨겨진 모델 값 보존,
  API 키 빈칸 유지, 소수 Temperature, 특수문자 프롬프트 저장·재표시를 검사했다.
- 같은 검사를 기존 test.3에 적용하면 역할 카드 부재로 실패하고, 수정본에서는 통과한다.
- 생성된 PC 기본/개별 연결 화면과 모바일 화면을 직접 이미지로 확인했다.

시험 기록과 스크린샷은 작업 루트의 `.tmp-feedback-43/preprocessing-ui-test4/`에 있다.
이는 로컬 브라우저 UI 검증이다. 사용자가 설치한 RisuAI에서의 표시, 실제 API 저장,
유료 제공자 호출·선정 품질·최종 주입 결과까지 검증했다는 뜻은 아니다.
