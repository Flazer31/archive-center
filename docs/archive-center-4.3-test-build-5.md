# Archive Center 4.3.0-test.5

2026-09-06 공통 프롬프트 편집 및 담당별 AI 연결 보완 테스트 빌드.
상태: `implemented_unverified` — 실제 RisuAI와 유료 제공자 검증은 별도다.

## 수정 내용

- 공통 프롬프트를 화면에서 편집·저장·기본값 복원할 수 있다. 사용자 수정본은
  번들 공통 지침을 대체하며 숨겨진 기본 지침을 추가로 붙이지 않는다.
- 각 호출에는 선택한 공통 지침, 해당 담당의 전용 프롬프트, 기존 단계별 과제를
  조립한다. 1차와 보충 분석은 같은 요청에서 읽은 설정을 사용한다.
- 다섯 담당의 새 설정은 각자 제공자·API 주소·모델·키를 지정하는 방식이 기본이다.
  출판사 연결 공유는 선택 사항이며 기존에 저장한 공유 여부를 임의로 바꾸지 않는다.
  공유를 선택해도 담당 프롬프트를 출판사 프롬프트로 바꾸지 않는다.
- 공통 수정본은 기존 `memory-preprocessing.json`의 `shared_prompt`에 저장한다.
  빈 값은 기본본 사용이며 구형 클라이언트가 PUT에서 필드를 생략하면 기존 값을 유지한다.
  ViewModel은 저장값, 실제 적용 본문, 복원할 번들 기본본을 구분한다.
- 설정 저장에 실패하면 실패를 표시하고 편집 내용과 재시도 가능한 저장 버튼을 유지한다.
- 추천이 없을 때의 기존 Go 선정, 기억 접근 범위와 저장·출력 경로는 변경하지 않는다.
- **이번 빌드는 Go 백엔드도 변경했다. 새 백엔드와 플러그인을 함께 사용한다.**
- JavaScript 변경량: test.4 패키지 대비 **22줄 추가, 12줄 삭제**.
  화면 편집·저장 전달·버전 표시 변경이며 프롬프트 조립과 저장은 Go가 담당한다.
