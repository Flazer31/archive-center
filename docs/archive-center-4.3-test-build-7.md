# Archive Center 4.3.0-test.7

2026-09-07 Endpoint 라벨, 역할별 기본 프롬프트 보강, API 키 편집 방식 수정.
상태: `implemented_unverified` — 실제 RisuAI와 유료 제공자 품질 검증은 별도다.

## 사용자 화면과 키 저장

- 주소 입력 라벨을 `Endpoint`로 변경했다.
- 저장 후 비어 보이던 API Key를 비밀번호 입력칸에 유지한다. 저장·화면 재진입·백엔드
  설정 재로드 후에도 다시 입력할 필요가 없도록 기존 저장값을 반환한다.
- `저장된 API 키 삭제` 체크박스를 제거했다. 키를 바꾸려면 입력칸을 수정하고 저장한다.
  지우려면 입력칸을 비운 뒤 저장한다.
- Go 설정 요청은 명시된 `api_key`를 적용하며 빈 문자열은 삭제다. 필드 생략은 기존 값
  유지다. 별도 `has_api_key`/`clear_api_key` 필드는 제거했다.
- 설정 응답은 이제 자격 증명을 포함하며 `Cache-Control: no-store`를 사용한다.
  키를 AI 프롬프트/입력이나 새 진단 항목에 넣지 않는다. 기존 오류 키 가림은 유지한다.
- 사용자 데이터 파일을 직접 수정하지 않는다. 변경은 새 백엔드와 UI의 설정 경로에 적용된다.

## 기본 프롬프트 보강

Go의 `multiAgentRolePrompts` 기본본을 수정했다. 각 담당에 장면 판단, 근거 선택,
추가 검색, 담당 간 요청, 최종·보충 추천 기준을 구체적으로 제공한다.

| 담당 | 구체화한 기준 |
| --- | --- |
| 사건·진행 이력 | 원인·행동·결과의 연결, 발생 시점과 회상 시점, 실행과 계획, 요약과 개별 사실의 역할 |
| 인물의 객관적 상태 | 지속 특성과 임시 상태, 상태 변화 근거, 소유·점유·사용 가능성, 관측 능력과 주장 구분 |
| 개인 경험·관계·비밀 | 직접 경험·전언·추측·오해, 관계의 방향성, 공개 정보와 실제 인지의 차이, 비밀 보유와 공개 권한 |
| 세계·장소·물건 | 세계 규칙과 지역 예외, 장소의 변화, 물건의 정체·상태·위치·소유, 근거 없는 설정 보충 방지 |
| 미해결 목표·복선 | 약속·희망·제안의 구분, 진행·보류·완료·취소, 조건과 기한, 완료 근거 부재를 미완료 확정으로 취급하지 않기 |

각 지침은 누락된 근거를 사실로 만들지 않고, 유용한 근거의 시점·관점·불확실성을
보존하도록 설명한다. 전체 이력을 다시 쓰거나 다음 서사를 결정하는 역할은 부여하지 않는다.
기존 공통 JSON 계약, 후보 범위, 분석 횟수, Go 기본 선정 경로는 변경하지 않는다.

저장된 사용자 수정본은 유지한다. 기본본을 사용 중이면 새 백엔드의 보강본을 사용한다.
사용자 수정본을 새 기본본으로 바꾸려면 **각 담당의 기본값 복원 → 전처리 설정 저장**을
사용한다. 본 변경은 기본 지침 개선이며 실제 모델의 선정 품질 향상 증거는 아니다.
