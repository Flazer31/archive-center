# Archive Center 4.3.0 배포 검증

상태: 정식 배포 준비 중. 2026-09-09.

4.3.0-test.23 작업과 OpenCode Zen·Go 제공자 추가를 정식 4.3.0 소스로 전환했다.
GitHub 공개·패키지·실행 검증은 실제 완료 후 아래에 기록한다.

- OpenCode Zen·Go / OpenRouter: 생산 호출기를 사용하는 HTTP 요청·정규화 회귀 통과.
- 실제 제공자 API 키 호출과 RisuAI 로딩 검증은 자동 회귀와 구분한다.
- 기존 사용자 업데이트와 신규 설치의 검증은 진행 중이다.

변경량: 첫 정식 준비 커밋 JS +26/-15행(기존 test.22~23 변경 포함), Go 추가 커밋 JS +17/-8행. Go 추가는 제공자 UI와 기존 세션 관찰값의 프록시 전달이다.
기본 버전이 4.3.0으로 바뀌어 구버전·test 채널을 고정한 회귀 기대값도 함께 최신화했다.
Windows 실제 신규 설치 진입점과 5개 POSIX 패키지 생성/시작 계약 검사는 통과했다. 외부 다운로드/시작은 해당 검사에서 fixture 경계다.

## 소스 검사

- Go 1.26.6: 전체 Go 테스트와 vet 통과.
- JavaScript 구문 검사 통과.
- Windows 신규 설치 진입점과 POSIX 생성 패키지 계약 검사 통과.
- 새 제공자 요청 51개 조합(17 경로 × 출판사/평론가/전처리 목적), 전처리 설정 전달, UI 추론 제어 회귀 통과.
- group_update.go, packageupdate/update.go, Windows 관리 실행기의 생산 코드는 공개 v4.2.0에서 변경되지 않았다. 릴리스 후보 ZIP 검사는 이 생산 HTTP 경로와 이전 공개 updater 실행 파일을 함께 사용한다.

OpenCode Go는 동일 세션의 목적별 호출·직접 프록시·5개 담당의 1/2차 호출에서 세션 헤더를 유지하고 다른 세션에서는 구분한다. 실제 구독 API 사용은 미검증이다.
