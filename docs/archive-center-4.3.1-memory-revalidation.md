# 4.3.1 기억 회수 — 구버전 공통 재현 재검사

검사일: 2026-09-10. 대상은 로컬 `4.3.1-test.3`에 포함된 기억 회수 구현이다.
공개 4.3.1 릴리스가 아니라 현재 작업 트리와 로컬 패키지를 검증했다.

후속 변경: [test.4](archive-center-4.3.1-test-build-4.md)는 아래 test.3 검증 이후 긴 대화의
단어 중복 확인 비용을 수정한 새 빌드다. 아래 버전 비교는 당시 결과이며, 현재 소스/바이너리
식별과 추가 조립·동등성 검사는 test.4 기록을 따른다.

**결론:** 이전에 재현한 최근 질의 간 경쟁에 따른 과거 기억 누락, 한국어 단서 회수 실패,
요약 행 전체의 중요도 오감점은 이번 공통 자료에서 회복됐다. 공개 사실을 따로 분리하지 않은
옛 혼합 요약의 누락과 검색 범위 밖의 기록은 남는다. 실제 제공자·운영 DB·RisuAI 본문 회상은
이 검사에서 확인한 것이 아니다.

2026-09-10 기준 확정: 사용자 결정으로 [4.3.1 기억 동작](archive-center-memory-recall-restoration-plan.md#memory-baseline-431)을
후속 버전의 비교 기준으로 고정했다. 아래 결과와 test.4의 추가 검사를 함께 인계한다.
이는 기준의 채택이며 아래 검사 수치·당시 빌드·미확인 범위를 새 실사용 결과로 바꾸지 않는다.

성공을 뜻하지 않으며, 전처리·출판사도 실제 외부 모델 대신 로컬 HTTP 응답으로 검사했다.

## 정렬·예산·전처리 회귀

현재 소스에서 별도로 **50개 최상위 테스트, 94개 세부 사례**가 통과했다.

- 정밀 기억의 의미 점수가 해당 사실에 연결되고 관련 없는 같은 인물의 다른 사실로 퍼지지 않음.
- 오래된 기억의 저장 중요도를 턴 경과만으로 다시 낮추지 않으며, 과거 사건을 직접 묻는 입력의 선정 유지.
- 같은 항목의 구조화된 현재 값 판정과 검색 점수 계산 분리.
- 표시용 요약이 중복돼도 서로 다른 하위 사실 후보 보존.
- 문자 예산과 분류별 우선 수, 전체 사실/출처/관점 전달 계약 유지.
- 전처리 끔·정상 추천·추천 없음·일부 역할 실패·보완 실패 × 출판사 끔/켬 **10조합** 통과.
  같은 40개 기록에서 예전 Top K 밖의 목표 기억이 최종 조립과 전달 계획까지 도달했다.
  이 조합은 사건·세계 두 담당을 활성화한 경로 검사이며 다섯 실제 모델의 품질 평가가 아니다.

추가로 **9개 전처리 테스트, 12개 세부 사례**가 통과했다. 병렬 호출과 일부 실패,
AI 추천 순서 유지, 양쪽 분석 라운드의 정확한 참조 전달, 공개/비공개 인계,
보완 검색 병합, 출판사와 로어북의 전달 경로를 확인했다.

## 검색 범위의 남은 한계

기록 180개, 길이 약 120/700자, 목표 순위 10/40/80/160, 예산 2,048/9,000/18,000자의
24가지 고정 자료를 기존 5개 조회와 현재 예산 기반 조회로 각각 검사했다.

- 기존 5개 조회는 이 자료의 모든 목표가 범위 밖이므로 0/24 도달.
- 현재 조회량에서는 범위 안 12개 모두 후보와 최종 기억에 도달.
- 범위 밖 12개는 그대로 누락. 모든 조립 결과는 최종 문자 예산 안에 있었음.

이는 50%의 실사용 기억 정확도라는 뜻이 아니다. 검색 순위를 시험에서 고정했고 범위 밖
대조군도 의도적으로 넣었다. 실제 Chroma가 목표 기억을 몇 위에 놓는지, 검색 단어가 모호할 때
회수하는지, 긴 세션에서 얼마나 느린지는 별도의 실제 자료로 확인할 부분이다.
