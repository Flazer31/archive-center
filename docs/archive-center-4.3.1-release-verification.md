# Archive Center 4.3.1 배포 검증

기준일: 2026-09-10. 사용자 요청에 따라 4.3.1 정식 공개를 준비한다.
현재 문서 작성 시점에는 공개 전이며, 태그·최종 파일·CI·공개 다운로드 확인은 아래에 후속 기록한다.

## 배포 범위

검증한 4.3.1-test.4의 기억 회수 복원, 맥락 조립 성능 수정, 세 서비스 포트 설정을 유지한다.
정식 버전 문자열과 빌더 기본값, OpenCode 클라이언트 버전 표기만 4.3.1로 맞춘다.
기억 정책·프롬프트·스키마를 추가 변경하지 않는다. 마이그레이션은 013까지다.

- [사용자 릴리스 안내](archive-center-4.3.1-release-notes.md)
- [로컬 후보 설치·업데이트 검증](archive-center-4.3.1-install-update-verification.md)
- [기억 비교 검증](archive-center-4.3.1-memory-revalidation.md)

사전 검증은 7개 패키지, 21개 이전 버전/OS preflight, 4.1·4.2·4.3의 실제 Windows updater
적용·rollback·재적용·commit, 변경 포트에서 격리된 Windows 01 실제 실행을 포함한다.
신규 설치의 외부 다운로드·서비스 경계 fixture와 실제 로컬 실행 범위는 사전 기록에서 구분한다.

## 보존 및 확인 범위

사용자가 실행 중인 백엔드를 교체하거나 재시작하지 않는다. 개인 DB·설정·API 키는 공개 대상이 아니다.
패키지 내부 JS 갱신과 RisuAI에 등록된 플러그인의 교체는 별개다.
소스·회귀·패키지·CI 통과를 모든 OS의 실제 신규 기기 설치나 본문 AI의 기억 활용 증명으로 해석하지 않는다.

정식 승격의 JS 변경량: +6/-6. 포함된 기존 기억 설정 UI 변경량: +1/-9. 합계 +7/-15.
