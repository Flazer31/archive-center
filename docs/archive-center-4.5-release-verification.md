# Archive Center 4.5.0 배포 검증

2026-09-17. 상태: **정식 공개 완료, 실제 공개 다운로드·설치·업데이트 검사 통과**.

[Archive Center 4.5.0 릴리스](https://github.com/Flazer31/archive-center/releases/tag/v4.5.0)는
한국 시각 **2026-09-17 14:19**에 stable/latest로 공개했다. 패키지 제작 소스는
`5d5d3698f4b1e9ab8130b8bb56f98a05ad53065a`다. 이후 검증 문서 갱신과 공개 소스 정리는 실행 코드 변경이 아니다. 4.5.0 태그에는
공개 소스 정리도 반영하며, 기존 설치·업데이트 ZIP 7종과 체크섬은 유지한다.

과거 작업과 위 제작 소스 식별자는 로컬 Git commit/tag 및 검증된 bundle에서 확인한다.
공개 저장소에는 검토한 현재 파일을 별도 이력으로 제공하며, 기존 개발 커밋은 로컬에만
보존한다. 이전 릴리스·태그·구버전 및 검증 브랜치는 파일 백업 후 공개 목록에서 제거했다.
아래 결과는 당시 검증 기록이며, 이전 공개 이력을 복구하라는 지시가 아니다.

test.7 누적 변경과 POSIX 설치 종료 수정을 정식 4.5.0으로 구성한다. 운영 DB·사용자 설정·실제 RisuAI 세션을 변경하지 않고 별도 환경에서 검사한다.

## 소스와 패키지

- 정식 버전 표시는 JS·Go·HUD·설치 패키지 모두 `4.5.0`이다. 이전 test 표기는 과거 기록에만 보존한다.
- 사용자 플러그인 도구 폴더와 개인 설정을 제외한 변경만 검토·커밋했다. 초기 소스와 차이는 로컬 기준점에 보관했다.
- Windows 설치/업데이트, Linux x64/arm64, macOS Intel/Apple Silicon, Termux arm64 ZIP 7종과 `SHA256SUMS-4.5.0.txt`를 제공한다.
- 전체 관리 파일의 SHA-256·크기, JS 원본, 실행 파일 OS/CPU, POSIX LF/실행 권한, migration 001~013을 확인했다. 로컬 환경 파일·DB·로그·런타임 캐시·설정·키는 포함하지 않았다.
- Git 이력 비밀 검사에서 나온 한 건은 기존 진단 테스트의 합성 비밀번호 문자열이었다. 이번 후보 변경 검사에서는 비밀값 검출이 없었다.

## 회귀 및 설정

- 로컬 전체 Go: **5,999 통과 / 환경 조건 16 건너뜀 / 실패 0**, 36개 패키지. `go vet`, JS 문법, 차이 공백 검사 통과.
- [후보 전체 CI](https://github.com/Flazer31/archive-center/actions/runs/35183417810)와 [정식 태그 소스 CI](https://github.com/Flazer31/archive-center/actions/runs/35184892274): Windows·Ubuntu·macOS, 실제 Chroma API, 빌드·취약점 검사 성공.
- [MariaDB migration CI](https://github.com/Flazer31/archive-center/actions/runs/35183417818): 별도 실제 MariaDB에서 성공.
- 배포 ZIP의 전체 JS와 Go를 브라우저에서 함께 실행해 설정 조회·저장·페이지 재열기, 전처리 추론 및 담당 설정 공유를 확인했다. RisuAI API 경계만 테스트 호스트이며 운영 세션이나 모델은 호출하지 않았다.

## 구버전 업데이트

- 공개 해시와 대조한 **4.1.0·4.2.0·4.3.0·4.3.1·4.4.0 × 7종 = 35개** 조합에 현재 updater의 실제 사전 검사를 적용했다.
- Windows **4.2.0·4.3.1·4.4.0 → 4.5.0**에서 패키지 적용·롤백·재적용·확정을 실행하고 관리 파일, 개인 설정 및 DB/포트 보존을 확인했다. 이 검사는 공개 전 GitHub 응답만 후보 파일로 대체했다.
- 4.4의 원래 JS 업데이트 버튼 코드를 Edge에서 실행해 확인 버튼 1회·적용 버튼 1회로 자동 재시작과 `committed` 상태를 확인했다. 별도 실제 MariaDB 기록, 환경 파일, 변경한 세 포트, 설치된 58개 관리 파일 해시가 유지됐다. 테스트 브리지만 제공한 브라우저 검사이며 사용자 PocketRisu 탭에서 직접 수행한 검사는 아니다.
- 일부 캐시의 4.3.1 ZIP이 공개본과 달라 GitHub에서 다시 받아 공식 해시 7종을 확인하고 35조합 검사 및 4.3.1 적용·복구 검사를 다시 통과했다.

## 신규 설치

- Windows 실제 `01_start_archive_center_windows.bat`: 한글·공백 경로, 신규 격리 DB, 저장한 서비스 포트로 시작 및 재시작 성공. MariaDB·Chroma 준비 완료를 확인했고 기존 사용자 프로세스는 유지됐다. 이 검사는 이미 설치된 의존성 실행 파일을 재사용했으며 의존성 신규 다운로드 검사는 아니다.
- Windows 공용 한 줄 설치와 패키지 계약 검사 통과. 기존 설치가 있으면 다운로드/파일 교체 전에 중단하는 경로, 해시/실패 처리도 검사했다.
- [Linux 실제 설치 CI](https://github.com/Flazer31/archive-center/actions/runs/35184463938): **네이티브 x64와 ARM64 모두 성공**. 공식 제작기로 만든 후보를 공용 설치 진입점에 제공하고 실제 의존성 설치, systemd 자동 등록·활성화, MariaDB/Chroma 준비, 관리 파일 해시, 서비스 재시작까지 확인했다. 공개 전 GitHub 조회/후보 다운로드 경계만 대체했다.
- 처음에는 읽기 권한 CI에서 draft 자산을 조회하지 못했고, Linux에서 Windows용 제작기를 실행한 검사 구성도 실패했다. CI 쓰기 권한을 확대하지 않고 기존 Windows 제작기 → 읽기 권한 artifact → 네이티브 Linux 설치로 바로잡아 위 성공을 확인했다. 이 두 실패는 제품 설치 실패로 집계하지 않는다.

## 공개 후 확인 및 한계

- GitHub latest가 `v4.5.0`이며 draft/prerelease가 아님을 확인했다. ZIP 7종과 체크섬 파일을 합친 **8개 원격 자산의 크기·SHA-256**이 최종 로컬 파일과 일치한다. 공개 raw main JS도 커밋된 원본 바이트와 일치한다.
- [공개 체크섬](https://github.com/Flazer31/archive-center/releases/download/v4.5.0/SHA256SUMS-4.5.0.txt)을 제공한다. 최종 재제작본의 실행 파일·설치 스크립트·JS·migration은 앞서 검사한 후보와 해시가 같다. POSIX 플랫폼 설명 파일의 제작 시각과 소스 식별 메타데이터만 갱신했다.
- [실제 공개 한 줄 설치 CI](https://github.com/Flazer31/archive-center/actions/runs/35185301204): 네이티브 **Linux x64·ARM64 모두 성공**. 사용자의 공용 명령 그대로 실제 GitHub latest를 조회·다운로드했다. 공식 ZIP 해시, 의존성 설치, systemd 등록·활성화, DB/Chroma 준비, 52개 관리 파일 해시와 서비스 재시작까지 통과했다. GitHub 응답 대체 없음.
- 수정하지 않은 **공개 Windows 4.3.1 → 4.5.0**, **공개 4.4.0 → 4.5.0** 모두 실제 GitHub `/update/check` → 다운로드·적용 → 실행기 자동 재시작 → `committed`에 도달했다. 각각 실제 격리 MariaDB 행, 환경 설정 파일, 저장한 세 서비스 포트를 보존하고 58개 관리 파일 해시를 확인했다. 이 단계는 기존 UI와 같은 백엔드 API를 직접 호출했으며, UI 버튼 코드 연결은 위 별도 Edge 검사로 확인했다.
- 격리 Windows 검사 프로세스는 종료됐고 검사 전 사용자의 백엔드·DB 프로세스는 유지됐다. 당시 검증 브랜치의 기록은 현재 로컬 Git 백업에 보존한다.

macOS는 네이티브 코드/설치 계약 CI, Termux는 패키지·업데이트 계약 범위다. 이번 배포에서 두 OS의 새 장비 전체 설치를 실행한 것은 아니다. Linux VM 검사는 OCI의 특정 계정·DNS·NPM·Cloudflare 환경이나 과거 제보 원인을 그대로 재현한 증거가 아니다.

원자료는 로컬 `_diagnostics/20260917-450-release/`에 보존한다. 개인 대화·설정과 테스트 DB는 공개 소스·ZIP에 넣지 않는다.

백엔드 업데이트와 RisuAI에 등록된 플러그인 교체는 별개다. 실제 모델의 기억 활용과 모든 사용자 환경의 동작을 배포 검사로 보증하지 않는다.

이번 정식 버전 전환에서 JS는 **+4/-4**이며 버전·빌드 안내 변경이다. 4.4 공개본 대비
4.5 전체 누적 JS 차이는 **+185/-44**다. 로컬 검사 원자료는 공개하지 않았다.
